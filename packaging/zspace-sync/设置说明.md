# 极空间团队文件 · 速影载体同步

映射配置：`~/.qr/suying-sync.json`，由速影 App 或 `install-sync-service.sh` 维护。

## 默认角色

- `sync_mode=carrier_only`
- 极空间：`/public/速影载体`
- 本机镜像：`~/Suying/carrier`
- 仅包含安装包、更新清单、可选配置种子和配置备份
- 客户片库、成片、数据库、缓存、账号令牌均不进入该角色

服务在每次同步前校验 `zspace.username` 与 `zspace.nas_id`；账号或设备不匹配时直接停止。绑定使用设备唯一 `nas_id`，不依赖 NAS 型号名。

## 可选媒体模式（v3 · 客户文件夹隔离）

媒体同步默认关闭。只有安装时明确提供 `--enable-media-sync --volume-uuid <UUID>` 才启用。

启用后必须在 `~/.qr/suying-sync.json` 的 **`media_sources`** 中为每个客户显式绑定团队空间下的**一个**子文件夹，例如：

```json
{
  "version": 3,
  "media_sync_enabled": true,
  "media_sources": [
    {
      "customer_key": "<客户名>",
      "remote_root": "手机相册备份/<子文件夹>",
      "local_target": "速影客户/<客户名>/01-片库/<子文件夹>",
      "pull_only": true
    }
  ]
}
```

- 同步脚本**只枚举**已配置的 `remote_root`，未映射文件不会下载（fail-closed）
- 不会回退遍历整个 `/public` 或共同父目录
- 更换来源时，旧目录下 ready 素材会归档，避免 cliplet 仍被选中
- 素材默认 **pull_only**，不回传成片/词池到团队空间
- 下载目的地必须位于显式 `local_target` 沙盒；`~/Suying/data`、`cache`、`render`、`runtime` 与 App Support 状态目录禁止写入
- 可重复使用 `--only-media-customer <customer_key>` 拆分规则；目的地互不重叠时可并行，重叠时 fail-closed

App 设置页：默认同步仅载体，新建客户**只需名称**（本机标准目录）。仅当 `media_sync_enabled` 时建客表单才展示「加载远端文件夹」；运维页可查看来源、更换来源、dry-run 预览。

服务每次运行按卷 UUID 查找当前挂载点，不依赖硬盘名称或固定 macOS 用户路径。

远端删除不会清理本地；大小一致的文件会跳过。

## 前提

1. 极空间客户端已登录并选中已绑定设备
2. 已在速影向导绑定账号与 `nas_id`
3. 已安装当前用户的 LaunchAgent `com.qr.zspace-team-sync`

## 自动任务 · `com.qr.zspace-team-sync`

| 触发 | 说明 |
|------|------|
| 登录 | `RunAtLoad` |
| 插盘 / 卷变化 | `StartOnMount`（仅显式媒体模式需要） |
| 每 10 分钟 | `StartInterval` 增量兜底 |

- 日志：`~/.qr/logs/zspace-team-sync.log`
- 最近摘要：`~/.qr/zspace-team-sync-state.json`

## 手动命令

```bash
~/QR/tools/zspace-team-sync.sh --dry-run
~/QR/tools/zspace-team-sync.sh
~/QR/tools/zspace-team-sync.sh --pull-only
~/QR/tools/zspace-team-sync.sh --push-only
~/QR/tools/zspace-team-sync.sh --pull-only --only-media-customer "<customer_key>"
launchctl kickstart -k "gui/$(id -u)/com.qr.zspace-team-sync"
```

## 单向媒体增量 · `com.qr.one-way-media-pull`（客户机）

| | 路径 |
|--|------|
| 远端 | `团队空间/手机相册备份/徐玲飞/Iphone/iPhone 11 Pro Max/iPhone 11 Pro Max相册备份/最近项目` |
| 本地 | `settings.paths.library_root` + `徐玲飞/HWABR-Q/HWABR-Q相册备份/Camera` |
| 例 | `/Users/xlf/Movies/速影工作区/速影客户/北京始峰伟业/01-片库/徐玲飞/HWABR-Q/HWABR-Q相册备份/Camera` |

只拉不推；同名同尺寸跳过；远端删除**不**删本地。LaunchAgent 每 **600 秒**跑一次（无 Terminal）。

```bash
# 在客户机（例 xlf-remote）
scp packaging/zspace-sync/{one-way-media-pull.py,one-way-media-pull.sh,install-one-way-media-pull.sh,zspace-team-sync.py} xlf-remote:QR/tools/
ssh xlf-remote 'bash ~/QR/tools/install-one-way-media-pull.sh install'
ssh xlf-remote '/bin/bash ~/QR/tools/one-way-media-pull.sh'   # 立即一轮
ssh xlf-remote 'bash ~/QR/tools/install-one-way-media-pull.sh status'
```

- 前提：极空间客户端已登录；片库目的目录在本机 APFS（Movies 工作区）
- 日志：`~/.qr/logs/one-way-media-pull.launchd.log`、`one-way-media-pull.log`
- 状态：`~/.qr/one-way-media-pull-state.json`
