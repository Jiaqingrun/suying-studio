# 极空间团队文件 · 自动同步（外置盘）

官方「文档同步」**无法选择团队空间**，因此改用本机 API 自动同步。

映射配置：`~/.qr/suying-sync.json`（速影 App「运维 → 安装同步服务 / 新建客户」维护）。

## 账号绑定（多设备必做）

配置项 `zspace.username` + `zspace.nas_id`：同步前校验极空间客户端当前登录账号与 NAS。不一致则**直接跳过**，不会串到另一台设备。

在 App 运维页点「刷新同步状态」后，从历史账号列表选「绑定 …」。

说明：无法在后台替你切换登录；必须在极空间客户端登录并选中绑定的那台设备。

## 路径

| 侧 | 路径 |
|----|------|
| 极空间团队空间 | `/public`（实际上传用 `/sata11/public/...`） |
| 本机外置盘 | `~/QR-Volume/极空间团队文件同步` |
| 引擎工作区（不同步） | `~/QR-Volume/速影工作区` |

## 新客户（标准布局）

远端与本机均为：

`速影客户/<客户名>/{01-片库,02-成片,03-词池}`

| 方向 | 内容 |
|------|------|
| **拉取** | 1:1（含片库） |
| **回传** | 仅 `02-成片`、`03-词池` |

在 App 向导点「使用标准外置盘布局」，或运维页「新建客户（标准布局）」。

## 遗留客户（北京始峰伟业）

远端仍用「手机相册备份」历史名；本机已迁到标准三层：

| 方向 | 内容 |
|------|------|
| **拉取** | `手机相册备份/{徐玲飞,车凯盛,成品视频,词池}` → `速影客户/北京始峰伟业/…` |
| **回传** | 本机成片/词池 → 远端 `手机相册备份/成品视频`、`词池` |

## 说明

- 引擎工作区 **不在**同步根内，不会上传
- 远端删除 **不会**清本地（防误删）
- 本地已存在且大小一致则跳过（增量）

## 前提

1. 外置盘 QR 已插入，并挂到 `~/QR-Volume`
2. **极空间客户端已登录**（本地代理 `127.0.0.1:13581`）
3. App 运维页已执行「安装同步服务」（脚本 → `~/QR/tools`，LaunchAgent `com.qr.zspace-team-sync`）

## 自动任务 · `com.qr.zspace-team-sync`

| 触发 | 说明 |
|------|------|
| 登录 | `RunAtLoad` |
| 插盘 / 卷变化 | `StartOnMount` |
| 每 30 分钟 | `StartInterval` 增量兜底 |

- 日志：`~/.qr/logs/zspace-team-sync.log`
- 最近摘要：`~/.qr/zspace-team-sync-state.json`

## 手动命令

```bash
~/QR/tools/zspace-team-sync.sh --dry-run
~/QR/tools/zspace-team-sync.sh
~/QR/tools/zspace-team-sync.sh --pull-only
~/QR/tools/zspace-team-sync.sh --push-only
launchctl kickstart -k "gui/$(id -u)/com.qr.zspace-team-sync"
```
