# V6 · 多客户隔离

目标：同一台机器、同一 `montage.db` 下按客户隔离片库/成片路径与素材/任务/日历，桌面切换「当前客户」即切换作用域。

## 模型

- **软隔离**：不拆 SQLite；`settings.active_customer` 决定当前作用域
- 每个客户持有 `library_root` / `library_roots` / `output_root`
- 素材、任务、日历、冷却用量均带 `customer_id` 过滤

## 范围

1. `Customer` 扩展路径字段；`Asset` / `Job` / `CalendarEntry` / `KeywordUsage` / `ClipletUsage` 增加 `customer_id`
2. 日历唯一约束改为 `(customer_id, day)`
3. `engine/catalog/customer_scope.py`：`effective_paths` / `require_active_customer`
4. 入库 watcher 仅监视当前客户片库；取片/冷却/运维按客户过滤
5. API：`GET/POST /customers`、`PATCH /customers/{id}`、`POST /customers/activate`
6. 桌面顶栏客户下拉 + 新建客户 + 路径绑定当前客户

## 验收（本机）

1. 迁移：始峰 18/18 素材已挂 `customer_id=1`
2. 「演示客户」空片库 → 素材 0；切回始峰仍 18 条
3. 演示客户 dry-run → blocked，clip 重叠 ∅
4. 同日日历：演示 `demo-theme` / 始峰 `default` 互不覆盖
5. `POST /customers/activate` 后 watcher 重建，scan 仅当前客户片库

## 非目标

- 多用户账号 / 权限
- 发布、数字人
- 每客户独立 SQLite
