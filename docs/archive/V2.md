# V2 开发范围（V1 之后）

目标：从「能手动出片」升级到「按日历日更、可无人值守跑满配额」。

> 成片质量问题（片段复用、主题不符、配文字色位置）见 [`BACKLOG.md`](BACKLOG.md)，**本阶段不优先改**；若本阶段改到取片/标题模块，再顺带消化 backlog。

## V2-A · 内容日历 ✅

1. 日历条目：日期 → 主题 / 分类 / 词包客户 / 模板 / 当日配额  
2. API：CRUD + 「今日计划」查询  
3. 创建任务时可一键「按今日日历开跑」  
4. 控制台增加「日历」页

## V2-B · 无人值守加固 ✅

5. 「每日自动开跑」开关 + 本地整点（默认关，可在系统页开启）  
6. 磁盘水位线：缓存盘/输出盘低于 `min_free_disk_gb` 禁止建任务  
7. 缓存清理：`POST /ops/cache/clean`（临时目录 + rendering 残留）  
8. 外置盘未挂载（`external_required`）时建任务返回 409
