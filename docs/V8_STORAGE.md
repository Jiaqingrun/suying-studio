# 速影 V8 — 外置盘存储布局

## 原则

极空间团队空间同步是 **NAS → 本机单向拉取**（`~/QR-Volume/极空间团队文件同步`）。

- **能给客户/同事在极空间里看到的** → 放同步区（片库 / 成片 / 词池）
- **只有引擎自己用的** → 放工作区（db / cache / render / logs），**永不**进同步树

本机 `~/Suying/data/settings.json` 只作启动引导，指向外置盘工作区。

## 目录树

```text
~/QR-Volume/
├── 极空间团队文件同步/                 ← 同步区
│   └── 速影客户/
│       └── <客户名>/
│           ├── 01-片库/                ← library_root
│           ├── 02-成片/                ← output_root（ready / review / failed）
│           └── 03-词池/                ← keyword_pack_path
│
└── 速影工作区/                         ← 不同步
    ├── db/                             ← data_root（montage.db + settings.json）
    ├── cache/                          ← cache_root（frames / library / proxies / temp）
    ├── render/                         ← render_root（渲染中间文件）
    └── logs/
```

## 路径配置（示例 · 样板客户）

以下仅为 **北京始峰伟业** 样板路径，不是产品默认。新客户用标准树：`速影客户/<客户名>/{01-片库,02-成片,03-词池}`。

| 用途 | 路径 |
|------|------|
| 片库 | `…/速影客户/北京始峰伟业/01-片库` |
| 成片 | `…/速影客户/北京始峰伟业/02-成片` |
| 词池 | `…/速影客户/北京始峰伟业/03-词池/…` |
| SQLite | `…/速影工作区/db` |
| 缓存 | `…/速影工作区/cache` |
| 渲染临时 | `…/速影工作区/render` |

引导文件：`~/Suying/data/settings.json`（与工作区 `db/settings.json` 同步写入）。

## 与极空间同步

配置：`~/.qr/suying-sync.json`（App「运维 → 安装同步服务 / 新建客户」写入）。

本机脚本 `~/QR/tools/zspace-team-sync.py`（launchd：`com.qr.zspace-team-sync`）：

| 客户布局 | 拉取 | 回传 |
|----------|------|------|
| **标准**（新客户） | 远端 `速影客户/<客户>/…` ↔ 本机同路径（1:1） | `02-成片`、`03-词池` |
| **legacy**（北京始峰伟业） | `手机相册备份/{徐玲飞,车凯盛,成品视频,词池}` → `速影客户/北京始峰伟业/…` | 成片/词池 → 手机相册备份对应目录 |

App 流程：运维页「安装同步服务」→ **绑定极空间账号+NAS** → 向导或「新建客户」建目录并登记。需外置盘挂载 + 客户端登录绑定账号。

工作区 `速影工作区/` 不在同步根内。详见同步目录旁 `设置说明.md`。

## 刻意不做

- 不把 SQLite / 抽帧 / 渲染临时放回同步区
- 不设独立 `cliplet_root`：抽帧统一在 `cache/frames`
- `02-成片` 下不再有 `rendering/`
