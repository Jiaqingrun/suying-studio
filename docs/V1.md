# V1 开发范围（MVP 暂过之后）

目标：从「能出片」升级到「按主题更准、镜头更好用、可抽检可报表」。

## V1-A · 智能取片基础 ✅

1. **Cliplet 可用片段** — 场景切分入库，生产优先用 cliplet  
2. **场景文字描述** — 当前启发式描述；Ollama 视觉可用后可升级  
3. **向量增量索引** — 本地表 + embedding（Ollama `nomic-embed-text`，不可用时 hash 降级）  
4. **标题-画面一致性** — 相似度分 + 阈值警告  

## V1-B · 成片观感与运营 ✅（基础版）

5. 开场钩子池强制（`{hook}｜{keyword}`）  
6. 横转竖裁切：`center` / `smart`（默认 smart）  
7. 封面候选 3 张（成片旁 `_covers/`）  
8. 简易抽检：控制台「抽检」页通过/打回  
9. 业务报表：产量、失败率、素材复用率、词分布
