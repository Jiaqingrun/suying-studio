# 速影 Content · SEO/GEO 软文边界（写死）

> **锁变更（2026-07-27）：** 用户批准 SEO/GEO 软文中枢计划并指令实现。

## 我们做什么

- 客户自有官网、多域名与本人官方账号的 **品牌知识内容** 生成、审核、排期、半自动发布
- 资料库 / 事实证据 / 主事实稿 / 平台变体 / 合规门禁 / AI 生成标识
- 受管 Chrome：无验证时 headless 静默填表提交；登录/验证码/改版 → 可见窗口停人
- 发布以「已发布 URL / 平台审核任务号」核验成功，不以「点了发布」冒充成功
- 消息页：脱敏摘要 + 本地回复草稿 + 打开官方深链人工发送
- **业务域隔离：** 软文（content）与视频（video）各自独立 Chrome 配置目录、登录会话、消息账号、未读红点与回复草稿；软文红点须逐条「预览」后才消失

## 明确不做

1. 软文站群、批量铺站、账号矩阵、伪装新闻媒体
2. 自动过验证码 / 滑块 / 对抗检测 SDK / Cookie 池导出注入
3. 自动输入并发送平台回复（仅草稿 + 官方页人工）
4. 把未校准平台标为「已支持发布」
5. 同稿多域名镜像灌站（须 canonical 或实质不同正文）
6. 百度百科营销词条自动提交；新闻源付费发稿冒充自有账号发布
7. 视频与软文共用同一 Chrome `--user-data-dir` / 登录态，或跨业务域猜测迁移登录配置

## UI 口径

> 客户自有站点与本人账号 · 事实约束生成 · 人工审核后发布 · 验证停人 · 回复在官方页 · 软文/视频消息与浏览器配置隔离 · 不做站群 / 矩阵 / 绕检测
