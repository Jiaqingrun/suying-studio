# 跟镜精品 · 片型合同（SCENE_TOUR）

> **效力**：跟镜精品（对内 `content_category=scene_tour`）领域合同。  
> **冲突**：不改写 L20 生活服务黄金底稿；跟镜与日常日更为并列片型。  
> **授权**：用户确认「跟镜精品 · 产品化建议」并指令实现（2026-08-13）；2026-08-16 迭代：有才排 / 人话导览 / 路线配方。

## 1. 定位

| 项 | 合同 |
|----|------|
| 对外名 | 跟镜精品 |
| 对内名 | `scene_tour`（禁止与 `premium`「精品样式」混用） |
| 主路径 | 站位硬库存 → 路线配方 → 选片 → 人话导览写词 → 成片检查 → 声画对齐 |
| 禁止 | 大词池金句作旁白正文；错场景硬凑；检查不通过仍出片；跨客户串味；**无库存站位仍安排** |

## 2. 与日常日更并存

- `default` / L20 服务口播：**不改**黄金底稿与 Ollama 仅润色合同。
- 生产页可提供「生成跟镜精品」主按钮；日常日更保留为次要入口。

## 3. 客户隔离

- 规则槽、场景分类、跟镜简报、标题小集、冷却、素材均按 `customer_id`。
- 行业骨架仅 `copy_on_bind` 成客户实例；出片禁止直读骨架句当旁白。
- `industry_key` 与客户 `profile.industry_pack` 不一致 → **未通过则不出片**。

## 4. 有才排（硬）

- 生产前统计各站位**硬库存**（grounding 通过 + 片源可用时长够）。
- **库存为 0 的站位：路线与旁白均不得安排**（含门头：仅描述含「招牌」不算真门头）。
- 必选站位硬库存为 0 → 拒片。
- 开场从库存 > 0 的站位中选，禁止虚构门头专场。

## 5. 路线配方

- 固定的是「开场—展开—收束」与邻接合理；不固定死序列。
- 按行业配方池抽路径（作业跟拍 / 货品沉浸 / 仓内漫步等），再按库存过滤；同站位不重复。
- **无真门头库存时不抽「从外到内」配方**。
- 成片检查的篇章顺序对照**本次路线站位**，不以整份行业骨架单调序卡死配方。
- 路径指纹写入成片 `content_fingerprint.route`。

## 6. 旁白与检查

- **宣传导览（跨行业/跨客户）**：像店主带看做**企业介绍**；断句分明（须有逗号两拍）；前半拍落画面锚点，后半拍用本客户企业口径加工。
- 简报注入 `enterprise_pitch`（企业资料短版/定位/口号/服务口径）；禁止大词池金句整段照抄。
- **禁止**：纯画面清点（摆放着/可见/一名女性/视觉描述复述）；雅词堆砌；机器物名；空壳营销；疗效承诺；**同片宣传收束短语复用**（如句句「您的舒适体验」）。
- 实现见 `engine/pack/scene_tour_diction.py`、`scene_tour_brief.py`。
- 画面锚定与错标自纠：假门头改标；校验失败排除坏片重选。
- **按镜配音（clip-aligned）**；单镜超片源则缩句/tempo/atrim；旁白明显长于画面 → 拒配音。
- 标题：客户标题小集（≤12）或手写；禁止 `list_title_pool`。标题色/描边走 `resolve_title_style`（VIDEO_LOCK → Job 冻结规则），禁止跟镜路径残留默认黄字导致 READY_GATE 连败熔断。

## 7. App 文案

用户可见一律简体中文。对照 `engine/pack/scene_tour_copy.py`。

## 8. 成功标准（摘要）

无片站位不进片；跨客户不串味；旁白可念像人；逐句可对画面；界面无英文裸奔。
