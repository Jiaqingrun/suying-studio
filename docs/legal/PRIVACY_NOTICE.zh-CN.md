## 1. 总则

速影 Studio 以**本机优先（Local-first）**设计：片库、成片、客户配置与发布登录态默认保存在本机，**不设默认公有云上传**。可选联网能力（如 Edge TTS、用户自配 ntfy）会出站，见下文。

## 2. 本机数据路径（典型）

| 类别 | 典型路径 / 机制 | 说明 |
|------|-----------------|------|
| 权威库 / 设置 | `~/Suying/data`（含 `montage.db`、`settings.json`） | 本机权威；不进极空间默认同步 |
| 片库 / 成片 / 工作区 | `~/Movies/速影工作区` 等（可在设置中改） | 本地媒体与产出 |
| 设备许可 | macOS Keychain / Secure Enclave（不可用时本机 Keychain 回退） | 单机绑定；非公有云账号体系 |
| Chrome 发布配置 | `…/Application Support/com.qr.suying/chrome-profiles` | 本人平台账号登录态；禁止 Cookie 池 / 多开矩阵 |
| 本地克隆 TTS（可选） | `~/Suying/runtime/f5_site_packages` + HF 权重缓存 | App 外 Kit；权重许可另见 NOTICE |
| 缓存 / 渲染临时 | 设置中的 cache / render 根 | 可清理；不含客户密钥 |

具体以本机「设置 → 路径 / 关于」与交付清单为准。

## 3. 出站与联网

| 能力 | 是否默认 | 出站内容 | 约束 |
|------|----------|----------|------|
| **Edge TTS（默认旁白）** | 是 | 口播**文本**经微软 Edge 在线语音服务合成 | **非全离线**；受微软服务条款约束；销售合同已提示甲方自行遵守 |
| Ollama 本地推理 | 本机 | 默认不出公网 | 模型装在本机 |
| ntfy 等通知（可选） | 否 | 用户配置的 HTTPS 端点；内容为**脱敏摘要** | 引擎含 SSRF 防护；不自动回复客户消息 |
| 应用更新 / 离线仓 | 运维通道 | 签名包校验；客户机安装阶段不依赖公网拉取模型（交付合同） | 见离线交付文档 |

关闭 Edge、改用本地 clone（若已清权并安装 F5 Kit）可减少旁白文本出站；不等同于整机断网。

## 4. 消息与发布

- 消息巡检：间隔与脱敏策略见产品硬锁；**不自动回复**。  
- 发布：人在回路；验证码 / 登录墙须人工处理。  
- 成片描述默认**不**附加「本作品由 AI 生成」等行（L14）；设置中提供**可选** AI 标识开关，**默认关**，依法需要时可开。

## 5. 第三方与模型

- 开源与第三方组件致谢：应用内「设置 → 关于」及 `NOTICE`。  
- F5-TTS / Vocos 等权重多为 **CC-BY-NC**：非商用许可；**不得**在未清权时冒充可任意商用再分发。  
- 客户自备素材、词包、声纹、BGM 的授权责任见销售合同。

## 6. 权利人联系

隐私与版权主体以销售合同乙方为准（工程占位：清闰 / QR）。正式对外联系方式以合同与交付材料记载为准。
