## 1. 语义证据分层

| 层 | 可证明什么 | 禁止 |
|----|------------|------|
| `coarse.v1` | 快速索引、普通生产候选、待严格验证 | 冒充 `semantic.v1`；进入 strict-only 选片 |
| 官方目录证据 | 官方目录中存在的规范中文名称、分类、型号及目录关系 | 冒充画面可见；补造颜色、数量、用途、动作或人物事实 |
| 画面事实 | 指定证据帧中直接可见的物品、场景、动作、文字与人物状态 | 用文件名、目录名、行业常识或官方目录替代视觉证据 |
| `semantic.v1` | 通过既有多帧 schema、证据与置信门禁的严格画面语义 | 由 coarse、目录匹配或人工改字段直接升级 |

1. 官方目录证据与画面事实必须分字段保存，并记录各自 `source_type`、来源标识、版本/摘要和时间。
2. 目录名称可用于规范化画面中已识别的物品名；无法建立画面证据时只能标记“目录候选/未知”，不得写入 `visible_facts`。
3. strict 资格只由既有 `semantic.v1` 视觉门禁产生；目录证据只能辅助命名与审计，不能替代门禁。
4. API、App、sidecar 与日志必须显示真实层级；`coarse`、`catalog_supported`、`strict` 不得合并成一个“已识别”状态。

## 3. 1080×1920 表达几何

以下距离均以最终 **1080×1920 或 1920×1080** 成片画布的可见字形外接框测量，不以 ASS baseline、字号、margin 或模板 offset 近似：

| 元素 | 写死要求 |
|------|----------|
| 标题 | portrait 默认顶部 220px/安全范围 120–420px；landscape 默认 120px/安全范围 60–260px；颜色/描边等必须等于 Job 冻结规则 |
| 旁白字幕 | portrait 默认底部 420px/安全范围 240–620px；landscape 默认 180px/安全范围 100–360px；颜色/描边等必须等于 Job 冻结规则 |
| 物品名称 | 中文单列竖排，字形从上到下；可选左侧或右侧 |
| 左侧物品名 | 可见字形最左边距画布左边 **80px** |
| 右侧物品名 | 可见字形最右边距画布右边 **80px** |

1. “单列竖排”指中文字符逐字自上而下排列，不旋转整行，不横排后旋转，不拆成多列。
2. 左/右是唯一位置选项；同一标签不得同时出现在两侧。
3. 输出只允许 1080×1920 portrait 或 1920×1080 landscape；不得随源素材分辨率漂移。
4. 标题/字幕颜色、描边、字号、对齐和轻量特效可按画幅规则配置；最终像素必须匹配冻结规则。字幕只烧一次、短句呼吸和声画对齐保持不变。

## 4. 向量运营状态机

1. **画幅隔离、各自最老优先**：横屏/竖屏分别按首次具备资格的 `eligible_at ASC`，再按稳定主键升序领取；重试不得刷新排队年龄，检索与生产不得跨画幅回退。
2. **只入队**：App/API 的“开始/继续向量化”只创建或恢复持久化队列项，不得在请求线程直接跑模型，不得把“已入队”报告为“处理中/已完成”。
3. **真实状态**：至少区分 `queued / running / completed / failed / abandoned`；计数必须来自持久化任务与已落盘向量，禁止按请求已返回或内存 future 推测。
4. **暂停语义**：收到系统或人工暂停时，放弃当前尚未完成的模型请求，将该次 attempt 记为 `abandoned`；已完成并原子落盘的向量必须保留，不回滚、不重复计算。
5. 暂停后未完成对象可保持/恢复为可重领队列项，但新 attempt 必须有新 ID；恢复仍按最老资格时间排序。
6. 超时、进程退出或结果不明不得标 `completed`；先核对持久化向量与 provenance，无法确认则进入 `failed` 或 `abandoned`。
7. 每个完成向量必须保留 customer、cliplet、输入摘要、embedding 模型/版本、语义层级与完成时间；跨客户领取为零容忍。
