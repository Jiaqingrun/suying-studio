## 0.8.9 · 蒙版贴图数值确认与自由摆放

缩放/旋转/不透明度可输入确认；蒙版与贴图取消标题区限制，可完全自由摆放。

- 缩放、旋转、不透明度：滑条 + 数字框，回车/失焦确认
- 蒙版/贴图可拖入标题区与画幅外，保存不再下推 y
- 覆盖安装仅换 App，不冲片库/词池/登录态

## 0.8.8 · 蒙版自由缩放旋转

导入蒙版/贴图可大幅缩放（可超出画幅）、旋转与越界拖动；成片烧录同步。

- 缩放 0.05×–12×（滑条/数值/滚轮）；旋转 ±180°；位置可越出安全框
- scale=1 约为画幅宽 40%；成片按同口径缩放旋转烧录
- 覆盖安装仅换 App，不冲片库/词池/登录态

## 0.8.7 · 导入蒙版画布预览修复

规则画布对导入的蒙版/贴图显示真实缩略图，不再只显示文件名手柄。

- user: 路径经 asset 协议渲染图片预览，可选中拖动与缩放
- 几何蒙版仍用标签手柄；表情贴图仍显示 emoji
- 覆盖安装仅换 App，不冲片库/词池/登录态

## 0.8.6 · 蒙版/贴图导入与转场库

规则页可导入本机 PNG 蒙版与贴图，转场改为中文芯片目录；补齐原视觉大改缺口。

- 蒙版：内置几何 +「导入蒙版图」；贴图：表情预设 +「导入贴图」；画布可拖
- 镜头转场库：常用中文芯片 + 完整 xfade 列表（不支持第三方特效包导入）
- 标题/字幕描边开关保留；覆盖安装仅换 App

## 0.8.5 · 竖排字幕可拖位与标题字幕开关

竖排字幕支持画布拖动与成片落位；规则面板可单独开关标题/字幕显示与烧录。

- 竖排字幕可上下左右拖；新增 subtitle_y_pct，烧录同步
- 标题/字幕「显示」开关（title_enabled / subtitle_enabled），关则不烧入成片
- 覆盖安装仅换 App，不冲片库/词池/登录态

## 0.8.4 · 规则画布拖动流畅化

画面布置拖动改为直接改 DOM、按帧合并，避免每帧 React 重绘描边文字导致的卡顿。

- 拖动期间不 setState，松手再写入规则
- pointermove 按 animationFrame 合并；拖动时改用轻量阴影代替描边
- 覆盖安装仅换 App，不冲片库/词池/登录态
