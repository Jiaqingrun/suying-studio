# 速影 Reach · 能力边界与非目标（写死）

> 效力同 [`DEV_LOCK.md`](DEV_LOCK.md)。触达（Reach）能力边界以此为准。  
> **锁变更（2026-07-24 · 四）：** Safari 半自动 / UI 辅助（风控自负）。  
> **锁变更（2026-07-24 · 五）：** 用户明确要求 **「视觉全自动（风控自负）」** → 允许 G5.V（见下）。

## 我们做什么

- 半自动发布队列：从 `publish_pack` **预填**标题/文案/视频路径  
- 打开**官方**创作者入口，并给出粘贴卡  
- **人在回路（产品默认）**：粘贴卡 + 人点发布  
- **可选 · G5.R Safari 半自动（风控自负）**：备料、开官方页、Finder/剪贴板；人点上传与发布  
- **可选 · G5.V 视觉全自动（风控自负）**：Agent 用 **截图/无障碍快照** 识别页面，自动点击、输入、推进发布流程；**验证码/登录/风控挑战仍必须人过**；仍限 **本人单账号**  
- 日配额、失败熔断、本机操作日志  
- 本机「发布待办」：汇总待办提醒 + 官方深链（**不**读平台私信）
- **本机 Chrome 独立用户目录一键打开**（串行换号：一次一个配置；人登录；非 Cookie 池）
- **按需创建多平台配置**：触达里选手台 + 数量创建本地 Chrome 配置并自动绑定平台（抖音/视频号/小红书/快手等）；**不**一次性预建空配置
- **可选 · 登录就绪后自动上传当前一条（G5.V）**：抖音可自动上传；**其它平台**打开官方页等人手动发；验证码/登录墙停人；不做多号连发
- **本机封面模板套**：App 缓存多套封面；每套按平台槽位（平台要 N 张则齐 N 张）；发布取「当前选用」模板
- **G7 本机消息巡检（本人账号）**：复用绑定的 Chrome `user-data-dir`，正式 Chrome `--headless=new` 静默串行打开官方消息页；固定每 1800 秒；只读未读数、发送者昵称、脱敏摘要与官方回复链接；App 提醒后由本人进入官方页回复

## G7 本机消息巡检 · 硬约束

| 允许 | 禁止 |
|------|------|
| 本机、本人账号、一次一个 Chrome profile | 多账号并发群控、Cookie 池 |
| 正式 Chrome headless 无可见窗口 + 本机 CDP 只读官方页面 | 导出/注入 Cookie、调用盗用私有凭证的服务 |
| 未读数、昵称、最长约 200 字脱敏摘要、官方 URL | 保存完整会话、默认截图、手机号等敏感信息 |
| 登录/验证码/profile 占用时停下并提示 | 自动过验证、强杀用户普通 Chrome |
| 点「去回复」打开该账号官方消息页 | 自动输入、自动发送或批量回复 |

消息巡检结果必须区分 `真实摘要`、`待人工登录`、`适配器已失效` 与 `仅建议检查`；不得把本机发布队列状态或抓取失败伪装成平台真实未读。

消息通知同时支持 App 有声提示、macOS 原生有声提示、可选 ntfy。三者必须去重并留审计；外发只含脱敏摘要和官方回复链接。ntfy 只允许 HTTPS（显式本机开发例外），防 SSRF、短超时，失败不得阻塞巡检；token/密码不回显、不进日志与交付产物。

## G5.V 视觉全自动 · 硬约束

| 允许 | 禁止 |
|------|------|
| 本机、本人、**单一**已登录账号 | 多账号矩阵 / 群控 / 养号 |
| 读速影物料；官方页上点击/填表/点发布 | 打码平台、滑块自动过、对抗检测 SDK |
| Cursor IDE Browser 快照+截图 或 Safari 截屏+键鼠 | 「反检测浏览器」作卖点 |
| 验证/登录 → **停并喊人** | 绕过登录、盗用他人 Cookie |
| 文件选择器若工具无法注入本地路径 → **停，请人选一次文件** | 无人值守连发多号 |

### 发布前门禁（写死 · 2026-07-24）

| 必填项 | 规则 |
|--------|------|
| 文案 | 平台正文/描述非空（pack 对应平台 `body`）；视频号 = 短标题 + 描述 |
| 封面 | 该平台规则要求的 **全部槽位** 都有本地文件；默认来自「当前选用的封面模板套」 |
| 门禁 | **未通过校验禁止点击「发布/发表」**；返回 `need_human` / `failed`，写明缺文案或缺第几个封面槽 |
| 小红书例外 | 网页封面编辑器经常报错/空白时：**封面失败仍允许点发**，队列记「封面待补」（平台默认帧），文案门禁不变 |

平台默认槽位数：抖音 1 · 视频号 2 · 小红书 1 · 快手 1（可配置）。  
有选用模板时以模板槽位为准；无模板时回退 `publish_pack` 的 `cover.jpg`（及 `cover_2`…）；槽位仍不齐则门禁失败（小红书封面见上例外）。

**责任：** 启用 G5.V 即接受误点、限流、封号、官方改版失败等后果；**不承诺**过检与长期稳定。

**运行时说明：** Cursor 内置浏览器与 Safari **Cookie 不互通**。若账号登在 Safari，须在 IDE Browser **再登一次**，或改走 Safari 截屏键鼠路径（见技能）。

## 明确不做（非目标 · 仍写死）

1. **不以「绕开平台机器人检测」为能力或卖点**  
2. **不做无人值守全自动多账号矩阵 / 养号 / 群控**  
3. **不自动回复私信**（G7 只读摘要 + 跳官方页人工回复）
4. **不绕过登录验证、不自动过验证码/滑块**  
5. **不提供「反检测浏览器」或同类对抗话术**  
6. **不做 Cookie 池 / 强制注入 Cookie 换号**（允许的是本机多 Chrome `user-data-dir` 串行打开）
7. **不使用第三方反检测/改指纹浏览器**；经用户本次明确授权，正式巡检仅允许官方 Chrome `--headless=new` 静默模式，页面异常即停

## UI 口径（触达 Tab）

> 默认人点发布 · 选手台+数量按需建 Chrome 配置 · 封面模板多套按平台槽位 · 文案+封面齐套才允许自动点发 · 抖音可自动上传 / 其它平台开页或 CDP · 本人账号每 1800 秒静默串行只读消息摘要并跳官方页人工回复 · 不提供自动回复 / 绕检测 / Cookie 池 / 矩阵养号
