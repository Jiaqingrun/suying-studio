# 速影 Reach · 非目标声明（写死）

> 效力同 [`DEV_LOCK.md`](DEV_LOCK.md)。触达（Reach）能力边界以此为准。

## 我们做什么

- 半自动发布队列：从 `publish_pack` **预填**标题/文案/视频路径  
- 打开**官方**创作者入口，并给出粘贴卡  
- **人在回路**：本人用已登录账号上传并点击发布  
- 日配额、失败熔断、本机操作日志  
- 本机「消息中枢」：汇总待办提醒 + 官方深链（**不**读平台私信）

## 明确不做（非目标）

1. **不以「绕开平台机器人检测」为能力或卖点**  
2. **不做无人值守全自动多账号矩阵 / 养号 / 群控**  
3. **不自动点击发布、不自动回复私信**  
4. **不绕过登录验证、不盗用他人账号 Cookie 做对抗风控**  
5. **不提供「反检测浏览器」或同类对抗话术**

官方入口与半自动辅助，是为了降低复制粘贴成本；**发布责任始终在操作人本人**。

## UI 口径（触达 Tab）

界面固定提示：

> 人点发布 · 不自动发帖 · 不提供绕检测 / 矩阵养号

若文档或 UI 与本文件冲突，以本文件 + DEV_LOCK 为准。
